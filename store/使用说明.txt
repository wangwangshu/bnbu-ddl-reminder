BNBU DDL Reminder — Microsoft Store 版

这是个人制作的非官方工具，与 BNBU 学校无隶属或认证关系。

1. 打开应用，点击“登录并同步”，在学校的 iSpace 登录页面自行登录。
2. 同步后，作业保存在本机。可直接添加作业或用“导入清单”选择 JSON 文件。
3. 点击“开机提醒设置”，在 Windows 设置 → 应用 → 启动中开启 BNBU DDL Reminder。
   未开启时，每次登录 Windows 后需要手动打开应用一次。
4. 关闭主窗口后，程序在托盘继续提醒。退出请用托盘菜单的“退出程序”。
5. 默认提前一天提醒；电脑关机、睡眠或未登录 Windows 时不会弹窗。
6. 学校登录会过期；若作业不更新，请重新打开“登录并同步”。

学校页面变化可能导致采集失败，请以 iSpace 原始截止时间为准。
应用不提供远程数据服务器、广告或分析服务。
本版不会扫描 Downloads 或自动导入旧版资料，迁移请手动选择清单。
数据与 WebView2 登录会话保存在当前用户的 BNBU-DDL-Store 本地应用数据中。
MSIX 的数据隔离与卸载清理由 Windows 管理，卸载前请自行保留需要的作业清单。

学校登录需要 Microsoft Edge WebView2 Runtime；缺少组件时，程序提供微软官方下载页。
源码和隐私说明：https://github.com/wangwangshu/bnbu-ddl-reminder

注意：本仓库生成的 MSIX 是未签名的商店提交包，不能作为已获微软签名的安装包分发。
必须通过 Microsoft Store 审核，由商店签名并分发后，才是正式商店版本。
