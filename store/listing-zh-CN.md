# 商店资料草稿

应用名称：BNBU DDL Reminder

简短说明：本地保存作业截止时间，提前一天提醒，支持 iSpace 同步和手动添加。

## 说明

BNBU DDL Reminder 帮助你把作业截止时间保存在 Windows 电脑上，并提前一天提醒。关闭主窗口后，程序可在右下角托盘继续运行。

你可以在内置学校页面自行登录 BNBU iSpace，同步 Dashboard Timeline 中能够识别的作业；也可以手动添加作业，或导入自己选择的 JSON 清单。支持标记完成和稍后 30 分钟再次提醒。

若希望登录 Windows 后自动提醒，请点击应用里的“开机提醒设置”，在 Windows 启动设置中开启本应用。电脑关机、睡眠或未登录时不会弹窗；程序退出后也不会提醒。

这是个人制作的非官方工具，与 BNBU 学校无隶属或认证关系。学校页面变化、登录过期或网络限制可能影响同步，请以 iSpace 原始截止时间为准。

学校同步需使用者本人的 BNBU iSpace 账号及学校允许的网络访问条件。手动添加、清单导入和本地提醒不需要学校账号。学校登录功能需要 Microsoft Edge WebView2 Runtime，缺少组件时可通过应用提示打开微软官方页面下载。

## 功能

- 提前 24 小时提醒作业截止
- 内置学校登录页和 Timeline 作业同步
- 关闭窗口后在托盘运行
- 手动添加作业和主动选择 JSON 清单导入
- 支持标记完成、稍后提醒和测试提醒
- 作业和提醒记录保存在本机，无项目自有远程服务器
